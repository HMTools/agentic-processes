# Available Agents

This project includes the following agents for the agentic-processes framework:

## step-executor

Executes individual process steps with context isolation. Use when a process step needs to be executed.

**Location**: `agents/step-executor.md`

## process-spawner

Spawns new processes and sub-processes with context isolation. Use when creating a new process from a template.

**Location**: `agents/process-spawner.md`

---

For more information, see the agent files in the `agents/` directory.
